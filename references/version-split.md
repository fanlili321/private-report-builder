# 版本拆分、合规脱敏与交付规则

来源：2026五周年暨半年报项目全流程沉淀（钉大确认版→清洁版→16个子版本→腾讯文档）。做正式稿拆分前通读。

## 一、三步交付流程（流程文档固化）

1. **整理清洁版**：钉大确认版 → 新建飞书文档（放同一共享文件夹，不在确认版上改）→ 人工复核（空行/格式）。
2. **拆分子版本**：清洁版为母本，每个子版本**新建独立飞书文档**（同文件夹），拆完人工确认。
3. **制作交付物**：导出 docx → **导入腾讯文档**对外用（飞书导出/PDF样式会丢失，腾讯文档承载最终交付）；另建一份"各报告链接汇总"文档统一管理所有腾讯文档链接。

**红线**：钉大确认版/正式稿只读不改；每个版本新建文档，绝不在别的版本上直接改。

## 二、清洁版整理规则（第1步）

从确认版整理清洁版时，对留痕标记的处理（用户逐条确认过）：
- **带删除线的内容** → 连文字删除。
- **标红（text_color=1）** → 取消红色、保留文字。
- **红色的指令性标注**（"本图要删除""（内容来自投研，待钉大重点确认）"等过程性文字）→ 连文字一起删。
- **又红又带删除线** → 按删除线处理（删）。
- 加粗不动；其他一律不动；拿不准的先问用户，不擅自改删除线/标红以外的地方。
- lark-cli：删除线/标红在 `text_element_style` 里；PATCH `update_text_elements` 去色，DELETE `children/batch_delete` 删块（降序删，删完重拉刷新索引）。

## 三、⭐版本拆分矩阵（2026半年报最终定稿）

✓=保留 ✗=删。"仅投教"=删该策略**业绩表现节**，保留策略理念/运作回顾/分红/未来展望。

| 内容 | C5 | C4 | C3 | 公开版 | 持有人版 |
|---|---|---|---|---|---|
| 五年业绩回顾 | ✓天益1+365 | ✓天益1+365 | ✓仅365 | **✗整节删** | ✓天益1+365 |
| 客户盈利(金额/比例/分红) | ✓数字 | ✓数字 | ✓数字 | **✗改定性** | ✓数字 |
| 复购率/留存率 | ✓ | ✓ | ✓ | ✓ | ✓ |
| 主动优选·业绩表现 | ✓ | ✓ | ✗ | ✗ | 该产品(仅主动系版) |
| 指增·业绩表现 | ✓ | ✗ | ✗ | ✗ | 该产品(仅指增版) |
| 365·业绩表现 | ✓ | ✓ | ✓ | ✗ | 该产品(仅365版) |
| 月薪宝·业绩表现 | ✓ | ✓ | ✗ | ✗ | 该产品(仅月薪宝版) |
| 全天候·业绩表现 | ✓ | ✗ | ✗ | ✗ | 该产品(仅全天候版) |

- 持有人版：每产品一份（12份），只保留**前半部分 + 自己产品所属策略章节**，其他策略章节删除；客户盈利/里程碑/陪伴等firm级内容全版本相同。
- 新成立产品（全天候/目标星级，未满展示期）非C5版用模糊曲线+引导联系小助手。

## 四、⭐合规脱敏规则（只公开版触发，本次最重要）

私募产品**历史业绩、客户收益率/盈利金额/盈利比例/分红金额**属于**不能对不特定对象公开披露**的内容。**公开版（公众号发文）必须脱敏**：

1. **删掉整个"五年业绩回顾"节**（含天益1期18.2%、365的16.6%等产品收益）。
2. **删掉每个策略的"业绩表现"节**（含各产品收益/回撤/超额数字）。
3. **客户盈利章节改定性**——隐去具体数字，保留原意，不重写、不与前文重复。定稿采用的措辞：
   - 标题"为客户创造盈利达1.64亿元，权益类产品的盈利比例达100%" → **"为客户创造实实在在的盈利，权益类产品投资者普遍实现盈利"**
   - "累计为客户带来总盈利已达1.64亿元" → **"持续为客户创造实实在在的盈利"**
   - "盈利比例100%" → **"投资者普遍实现了盈利"**
   - "将超过6380万元的盈利进行分红" → **"通过分红的方式，帮助投资者把部分收益落袋为安"**（去掉6380万）
4. **"成绩单"三数字卡片图（1.64亿/100%/6380万）撤掉**，同一风险。
5. **复购率(75%)、留存率(90%)可保留**——属客户行为数据，非产品业绩。
6. **C5/C4/C3是风测等级匹配的定向推送，不算"公开"，业绩数字保留**。脱敏只针对公开版。

## 五、第二部分结构：嵌套 vs 扁平

- **多策略版（C5/C4/C3/公开）= 嵌套**：`第二部分 → 一、权益类策略 → 1、私募主动优选策略 →（1）策略理念（2）业绩表现（3）投资运作回顾（4）分红止盈机制介绍（5）未来展望；2、私募指数增强策略…；二、稳健类策略 → 1、365 → 2、月薪宝 → 3、全天候；三、目标星级策略`。
- **单产品持有人版 = 扁平**：`第二部分：私募XX策略上半年运作总结 → 一、策略理念 二、业绩表现 三、投资运作回顾 四、未来展望`（主动系多一节"分红止盈机制介绍"）；去掉"一、权益类策略/1、私募XX策略"两层包裹；H1标题含具体策略名。
- 扁平化技术：删包裹H2(…类策略)+H3(1、私募…策略)，把（1)-(N)的heading4改为一二三四的heading2（删块重建，改不了块type），改H1标题与引言主语。

## 六、其他固化规则

- **五年业绩回顾**：所有版本统一以标杆两产品（天益1期+365天惠1期）为例，**不是持有人自己的产品**；产品自己的数据只在第二部分"业绩表现"。C3特例只留365。三张标杆图（天益1走势/天益1回撤/365走势）全版本共用同源真图，可从任一版下载media再insert。
- **持有人版总结**：单策略版（"仟上的XX策略，成立以来…"），不用多策略版+两条bullet。措辞按产品真实表现——全天候(-1.37%)/稳健天泽不写"出色表现"，用"稳健运作/持续带来稳健回报"。
- **数据说明**：统一2条（①最大回撤按日频；②累计盈利含历史清仓+在持），删掉收益率公式第3条。
- **命名**：`【C5版】/【C4版】/【公众号发文】【公开版】/【持有人版-XX产品】` + 报告全名`：厚积薄发，行稳致远`。

## 七、PDF成品要求（领导对样例的@AI批注 + 去年成品对照）

自排版 HTML→PDF（脚本 `scripts/make_report_pdf.py`），对齐去年成品 `assets/2025年终总结成品样例.pdf`：
- **页眉**：仟上logo原图（assets/header_logo.png，968×58透明PNG）+ 金色分隔线，每页；页脚页码居中。
- **目录**：到二级标题（前/后半部分各自展开）；**文字与页码间要有虚线连接线**，**页码右对齐到页边**；目录单独成页。版本说明不进正文。
- **水印**：45°斜向"本文件不得转载或向第三方传阅"，思源黑体CN——**旋转必须用 `fitz.Matrix(-42)`，用 `Matrix(1,1).prerotate()` 会镜像反转**。
- **分页**：每个大标题（一、二…）前插分页符、另起一页；尾声也是；数据说明+风险提示单独一页（有数据说明时）；只有风险提示无数据说明时，风险提示接前面内容、前空一行。
- **中英文/数字间加空格**（盘古之白）：全文"365 增强""天益 1 期""FOF 策略""90% 的"，对齐去年成品。
- **陪伴长图**：两张长图各占一页、**同宽（固定宽度）保持大小一致**。
- **人工复核项**：图片居中、大小适中；**每页不能以图开头**（图落页顶要调前面文字/图大小）；避免整页只有一句话/一张图。
- 字体：OTF思源黑体经otf2ttf转TTF（assets/SHSCN-*.ttf），PyMuPDF只认TTF。
- 注：腾讯文档导入会丢这套排版，故PDF是独立交付物；若走腾讯文档则用朴素docx。
