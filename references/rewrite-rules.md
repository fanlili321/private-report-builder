# 报告写作与投研内容改写规则

来源：2026五周年暨半年报项目中王磊（磊哥）批注 + 钉大意见 + 人工终稿归纳。写报告文字前通读一遍。

## 一、投研内容 → 客户话术改写

投研团队给的原文是机构视角，直接放报告会被批注打回。改写原则：

### 1. 删机构术语（"不需要向客户解释这么细"）

以下内容对客户一律删除或降维：
- 收益互换、基差、贴水细节、交易对手、报价比价、清算稳定性
- 风险补偿、风险预算、因子暴露、久期细节（可保留"短久期高等级债"这种程度）
- "协议指增底层是期货贴水"之类的实现机制 → 改成"叠加了指增策略"
- 产业分析长篇（如AI产业变革的技术扩散意义）→ 一句话带过

### 2. 统一改写为"买方叙事"模板

**权益类策略（主动优选/指增）遇到跑输或高估**：
> 市场极端分化/某类品种涨多了 → 估值逐渐抬升 → 策略不追高，坚持估值与长期回报的匹配 → 涨出收益的部分做分红止盈/分批止盈（有具体金额就写，如"止盈金额超过6380万元"）→ 短期可能跑输指数，但风格会均值回归，低估布局+高估止盈有助于长期回报 → 对超额收益的持续性有信心。

**稳健类策略（365/月薪宝）遇到短期亏损**：
> 底层约X%股票偏红利价值风格 → 本轮是成长风格牛市，价值阶段性低迷，策略短期承压 → 但价值资产的核心吸引力没有消失：估值压力释放+股息回报仍在 → 短期低迷反而带来更好的长期配置性价比 → 坚持既定框架，耐心等待价值风格修复 → 长期充满信心。

**未来展望统一框架**：
> ①继续用好XX等多种做法，拓宽收益来源；②坚持买方服务：低估时提示买入机会，高估时做好分红止盈、落袋为安。

**钉大金句收尾**（主动优选展望末尾用过）：
> 我们做的事情也不变：跌出机会就买入，涨出机会就卖出，其他时间耐心等待。

### 3. 保留标记

投研来源的段落，标题后缀"（内容来自投研，待钉大重点确认）"，提交前提醒钉大终审。

## 二、措辞规范（批注逐条纠正过的）

| 规则 | 说明 |
|---|---|
| 正收益不加 + 号 | 写 7.10%，不写 +7.10% |
| "组合" → "策略" | 对客户统一叫策略 |
| 产品线叫法 | 私募500指增、私募1000指增、私募红利指增（不是"指增500"） |
| 严谨表述 | 不说"持有不满1年的投资者是亏损的"，说"只有少部分是略微亏损的"（除非确实全部亏损） |
| 亏损措辞 | 用"暂时浮亏""略微亏损"，配"随时间推移逐步转正有信心"的承接 |
| 口语短句 | 学历史报告：短句、分行、"像XXX，都属于这一类""还是相当不错的" |
| 策略总览写法 | "第一类是权益类策略：…这类策略…像XX、XX，都属于这一类"叙述式，不用干巴巴的bullet |

## 三、客户盈利章节写法（报告重头戏）

老板原话："客户记不住策略跑赢跑输，核心是站在客户角度盈利如何，再怎么突出都不为过。"

**定稿结构**（四、客户盈利情况）：
1. 开头：评判产品不光看策略表现，更要看投资者的盈利。
2. **权益类100%打头**：为客户创造盈利达X.XX亿元，权益类产品投资者的盈利比例达100% + 分档列举 + 权益类分布图。
3. 整体口径：持有仟上产品的投资者盈利比例约XX%；满1年以上100%；不满1年只有少部分略微浮亏。
4. 分红止盈数据点（如有）：2026年初将超过6380万元盈利分红。
5. 具体产品案例（天益1期）：100% + 分档 + 分布图。
6. 复购率（逆势投资）+ 留存率（长期持有）：沿用四周年报告框架，跟封闭式公募20%留存率对比。

**分档表述固定格式**（逐行列举，不用表格）：
```
盈利超过15%的投资者，占比87.36%
盈利超过20%的投资者，占比57.14%
盈利超过25%的投资者，占比29.12%
```
分档占比 = 分布图对应柱子之和，发稿前自查加总是否对得上（批注纠错过两次）。

**多维挖掘方向**（数据好就写）：持有时长分组（满1年/3年/5年盈利比例、老客户人均盈利额）、盈利金额分布（超100万/50万/10万人数、中位数）、浮亏客户画像（人数占比、全是新客户、幅度小、人均金额 vs 盈利人均）。

## 三·五、大数字卡片图（领导逐轮确认的定稿规格，2026半年报）

三个头条数字（累计盈利/盈利比例/分红止盈）做三联卡片图，PIL绘制：
- 布局：**三等卡、无单卡强调**（曾试过分红大卡版和C位描边版，领导最终选平权三卡）；标题"五年，交给投资者的成绩单"。
- 样式：白底2130x900、卡片#FBF4E6圆角28、大数字#C25A12(150pt)+单位小号、标签#5A3317(40pt粗)、小注#6E5D46。
- 文案定稿：1.64亿小注"包括当前持仓收益与已实现收益"；100%小注"若一个投资者持有多只产品，合并计算收益"（口径放卡内，不放底注）；6380万小注"通过分红帮助投资者落袋为安"。
- 底注只写"数据来源：仟上投资，截至XXXX年X月X日。"，**左对齐（与卡片左缘对齐）**——截止日期只出现在底注一处，卡片小注里不重复；口径长句不放底注。
- 产品名带"私募"前缀（如"私募主动优选"）。

## 四、口径说明与数据说明（文末固定格式）

```
数据说明：
1、最大回撤按日频统计，即根据每个交易日公布的净值来计算最大回撤数据。
2、累计盈利的统计口径包含历史清仓用户、当前在持用户。
3、持有人收益率指累计收益率，计算公式为：累计收益率=（当前持仓资产-累计入金+累计出金）/累计入金。统计区间为各产品成立以来至XXXX年X月X日。盈利比例按投资者统计，同一投资者持有多只产品的，合并计算其全部持仓的累计收益。
```

风险提示固定：本报告所载信息仅供仟上存量持有人参考，不构成任何投资建议或对未来收益的承诺。基金过往业绩不代表其未来表现，市场有风险，投资须谨慎。

## 五、初稿附带"修订备注/待确认事项"节

初稿和修订稿末尾放一节（标注"发布前删除本节"），列：待投研/运营补的素材、待钉大拍板的决策（如偏股基金指数是否保留）、本轮改动清单。方便审核，避免口头交代遗漏。
